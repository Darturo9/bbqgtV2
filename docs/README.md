# Documentación de BBQBros V2

Esta carpeta es la fuente canónica para decisiones, alcance y operación. La documentación debe
actualizarse en el mismo cambio que modifica su comportamiento.

## Rutas

- `product/`: problema, alcance, actores y reglas del negocio.
- `architecture/`: componentes, límites, ambientes y flujos técnicos.
- `decisions/`: registros de decisiones arquitectónicas aprobadas.
- `plans/`: diseños y planes de cambios concretos.
- `runbooks/`: procedimientos operativos y de recuperación.
- `glossary.md`: vocabulario compartido.

separado. No se documentan valores de secretos.
