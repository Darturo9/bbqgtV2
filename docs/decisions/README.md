# Registros de decisiones arquitectónicas

Los ADR conservan el motivo y las consecuencias de decisiones costosas de cambiar. Un ADR aceptado
no se edita para ocultar una decisión anterior; una nueva decisión lo reemplaza mediante otro ADR.

Estados permitidos: `proposed`, `accepted`, `superseded` y `rejected`.
