# Visión del producto

## Problema

BBQBROS necesita controlar su experiencia de pedidos a domicilio sin depender de un conjunto
desordenado de flujos, integraciones y decisiones difíciles de rastrear. El sistema debe servir al
cliente y a la operación del restaurante sin convertir cada cambio en un riesgo para pagos,
facturación o entrega.

## Visión

Construir una plataforma propia, confiable y comprensible que permita recibir, confirmar, preparar,
despachar y completar pedidos a domicilio, con seguimiento de pagos, FEL y entrega desde un único
flujo auditable.

La plataforma estará preparada para varias marcas y sedes. BBQBROS será la única marca habilitada
durante el lanzamiento inicial. BWINGS se evaluará después de un periodo aproximado de tres meses de
estabilidad productiva.

## Principios

- El negocio define el comportamiento; las integraciones se adaptan a él.
- El servidor decide precios, cobertura, disponibilidad y transiciones.
- Una orden debe poder rastrearse de extremo a extremo.
- Los fallos externos no deben duplicar órdenes, cobros, facturas o despachos.
- Cada ambiente debe reconstruirse mediante código y documentación versionados.
- Se construye únicamente lo necesario para el lanzamiento aprobado.

## Responsable

Codex será el único agente de programación. El propietario del proyecto mantiene la autoridad sobre
negocio, proveedores, credenciales y producción.
