# Alcance del MVP

## Incluido

- Arquitectura multimarcas con BBQBROS como única marca activa.
- Varias sedes de BBQBROS.
- Catálogo, productos, modificadores, precios y disponibilidad.
- Carrito y checkout como invitado.
- Pedidos exclusivamente a domicilio.
- Asignación automática de sede por cobertura.
- Efectivo contra entrega y tarjeta mediante NeoPay.
- Confirmación operativa antes de solicitar FEL.
- Panel administrativo y panel operativo.
- Roles `platform_admin`, `brand_admin`, `location_manager` y `operator`.
- Seguimiento público mediante token seguro.
- WhatsApp con respuesta fija y notificaciones transaccionales.
- GoNau antes del lanzamiento, sujeto a documentación oficial.
- Contingencia manual de entrega.

## Excluido

- BWINGS habilitado para venta.
- Recoger en restaurante o pagar en mostrador.
- Cuentas e historial de clientes.
- Bot conversacional con IA.
- Órdenes creadas desde WhatsApp.
- Empleos, eventos, reseñas y promociones avanzadas.
- Analítica compleja.
- Aplicación propia para motoristas.

## Bloqueos conocidos

- Contrato técnico y reunión con GoNau.
- Validación fiscal final del momento de emisión FEL.
- Lista exacta de sedes y coberturas aprobadas.
- Decisión sobre qué datos del catálogo V1 se migrarán.

## Criterio para BWINGS

Después de aproximadamente tres meses de producción se revisarán estabilidad, pedidos completados,
errores, pagos, FEL, entrega y soporte. Estar preparado para varias marcas no autoriza construir
anticipadamente el flujo de BWINGS.
